III. Kode Semu (Pseudocode)

ALGORITMA HitungGajiKaryawan DEKLARASI golongan : string jamLembur : integer gajiPokok, persentase : real gajiLembur, totalPenghasilan : real DESKRIPSI INPUT(golongan) INPUT(jamLembur) IF golongan = "A" THEN gajiPokok = 5000000 ELSE IF golongan = "B" THEN gajiPokok = 6500000 ELSE IF golongan = "C" THEN gajiPokok = 9500000 ELSE OUTPUT("Golongan tidak valid") STOP END IF IF jamLembur < 0 THEN OUTPUT("Jumlah jam lembur tidak valid") STOP ELSE IF jamLembur = 0 THEN persentase = 0.00 ELSE IF jamLembur = 1 THEN persentase = 0.30 ELSE IF jamLembur = 2 THEN persentase = 0.32 ELSE IF jamLembur = 3 THEN persentase = 0.34 ELSE IF jamLembur = 4 THEN persentase = 0.36 ELSE persentase = 0.38 END IF gajiLembur = gajiPokok * persentase totalPenghasilan = gajiPokok + gajiLembur OUTPUT("Gaji Pokok = ", gajiPokok) OUTPUT("Gaji Lembur = ", gajiLembur) OUTPUT("Total Penghasilan = ", totalPenghasilan) STOP

2. Sejarah dan Perkembangan Bahasa Pemrograman Java

Java dikembangkan James Gosling di Sun Microsystems tahun 1991 (awal bernama Oak) dengan konsep *Write Once, Run Anywhere* (WORA). Diakuisisi Oracle Corporation tahun 2010.
